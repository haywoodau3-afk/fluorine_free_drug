# Historical source paths

The proposal and review tables retain original source paths and original input hashes as historical provenance. These paths describe the development records and are not paths to open directly in this repository.

[original_path_map.csv](original_path_map.csv) resolves the nine identified historical path strings to files distributed here. It records whether the destination is a selected-column export, corresponding state-keyed evidence, or curated source notes. Original hashes identify the development inputs; packaged hashes identify the exported files. They need not match. The pair-input exports preserve all rows and source order and omit free-text assay descriptions where present. They add source access without changing any generated design, score, cohort or outcome.

Use the stated state, molecule, assay, document or selection identifiers to join records. The source notes preserve the limits of the original literature reviews. Third-party attribution and reuse terms are in [SOURCES.md](../SOURCES.md).
